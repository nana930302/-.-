## 核心文件详解

### 应用入口文件
- **app.js**：全局应用逻辑，初始化应用数据
- **app.json**：配置页面路由、窗口样式、导航栏
- **app.wxss**：全局 CSS 变量和基础样式

### 启动页面（Launch Page）
启动页面是用户打开小程序时看到的第一个页面，展示品牌形象和欢迎动画。

**文件**：
- `pages/launch/launch.wxml`：包含完整的 SVG 卡通形象（喵喵和汪汪）
- `pages/launch/launch.wxss`：所有动画效果和视觉设计
- `pages/launch/launch.js`：控制动画播放和3.5秒后自动跳转

**特色动画**：
- 文字进场动画（fadeInDown）
- 卡通人物进场动画（fadeInUp）
- 卡通人物浮动效果（bounce）
- 头部摇晃动画（headShake）
- 加载点动画（dot-bounce）

### 主页面（Index Page）
主页面是用户进入小程序后的主要界面，提供服务和功能入口。

**文件**：
- `pages/index/index.wxml`：主页布局，包括推荐卡片和功能菜单
- `pages/index/index.wxss`：主页样式和交互效果
- `pages/index/index.js`：点击事件处理逻辑

**主要功能**：
- 显示喵喵（午餐推荐）和汪汪（晚餐推荐）的推荐卡片
- 提供4个功能入口（随机推荐、我的收藏、评分排行、设置）
- 用户友好的点击反馈

## 卡通形象技术实现

### 喵喵（小猫）SVG 构成
```
- 头部圆形（主体）
- 立耳朵 × 2（内耳粉色）
- 眼睛 × 2（黑色瞳孔+高光）
- 粉色鼻子
- 微笑嘴巴
- 白色胡须 × 4
- 身体椭圆
- 爪子 × 2
- 毛发纹理（多个重叠圆圈）
```

### 汪汪（小狗）SVG 构成
```
- 头部圆形（主体）
- 垂耳朵 × 2（内耳棕色）
- 眼睛 × 2（黑色瞳孔+高光）
- 黑色鼻子
- 嘴巴 + 舌头
- 身体椭圆
- 爪子 × 2
- 卷尾巴（路径）
- 毛发纹理（多个重叠圆圈）
```

### 毛茸茸效果实现
使用多个 `<circle>` 元素重叠在一起，创建毛发效果：
```xml
<circle cx="70" cy="75" r="8" fill="#FF9F5A"/>
<circle cx="75" cy="60" r="7" fill="#FF9F5A"/>
<!-- ... 更多圆形 ... -->
```

## 关键技术点

### 1. SVG 矢量图形
- 使用 SVG 绘制卡通形象，支持任意缩放
- 通过 `<svg>` 标签内联嵌入，无需额外图片文件

### 2. CSS 动画
- 使用 `@keyframes` 定义复杂动画
- 组合多个动画实现丰富的视觉效果

### 3. 响应式设计
- 使用 rpx（小程序响应式单位）
- 在 `@media` 中实现小屏幕适配

### 4. 页面路由
- 使用 `wx.redirectTo()` 实现页面跳转
- 启动页自动跳转到主页面

### 5. 事件处理
- 使用 `bindtap` 处理用户点击
- 使用 `wx.showToast()` 显示反馈信息

## 快速修改指南

### 修改应用名称
1. 编辑 `app.json` 中的 `navigationBarTitleText`
2. 编辑 `pages/launch/launch.wxml` 中的 `.app-title` 文本

### 修改颜色
1. 编辑 `app.wxss` 中的 CSS 变量
2. 编辑 `pages/launch/launch.wxml` 中 SVG 的 `fill` 属性

### 修改启动页文案
编辑 `pages/launch/launch.wxml` 中的 `<text>` 标签内容

### 修改主页推荐
编辑 `pages/index/index.wxml` 中的推荐卡片内容

### 修改功能菜单
编辑 `pages/index/index.wxml` 中的 `.feature-item` 元素
